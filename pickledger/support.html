PickLedger helps you compare picked packages with the individual units expected on one order. It does not update inventory or connect to an ERP.

Guide for version 1.0 · September 26, 2026 · iOS/iPadOS 17 or later.

Set up the order

  1. Choose Create an order or New order. Enter an order reference, unique SKU and expected individual units for each item.
  2. Enter or scan a package code. Explicitly set the units inside that package. Add other case or inner-pack codes using the order’s package-code editor before counting.
  3. Save. Plan and package rules can be edited before the first count. Once a count is recorded, corrections use the audit history.

Codes match exactly, including leading zeros. A barcode does not tell PickLedger how many units are inside. Scan a code when configuring it to use the same representation as the camera; some UPC codes are returned with a leading zero.

Count and correct

Choose Scan code or Type code. Review the SKU, package units and proposed total, then choose Count. A camera result never counts automatically. Unknown codes change no quantities. Undo last count adds a correction without deleting the original event.

You can close an order with discrepancies and reopen it later. Closed does not mean matched. Orders with recorded counts are retained so their history remains available.

Hand off the result

Use Export discrepancy CSV to save or share expected, picked, missing and extra individual units. Export count history CSV includes every count and correction with UTC timestamps. Both identify the order. Choose a Files destination and verify the saved file before relying on it.

Spreadsheet-like formulas in text are escaped. When opening CSV in a spreadsheet, import barcode and SKU columns as text to retain leading zeros; some spreadsheet applications otherwise convert them to numbers.

Free features and PickLedger Pro

Manual orders, package codes, camera/manual counting, undo, CSV exports and backups are free. The optional one-time Pro purchase adds CSV order import with saved column mappings and a reusable package-code catalog. It is not a subscription. Apple shows the current price before purchase.

Choose Restore purchases in PickLedger Pro using the Apple Account that bought it. If Apple is still approving a purchase, continue the free workflow and try again after approval. A refund or revoked purchase removes Pro features but does not delete your orders or prevent free counting, export or backup.

Import a CSV order with Pro

Choose Import order CSV, select a UTF-8 CSV up to 2 MiB and 1,000 item rows, and map the columns. Use one row per unique SKU, unique nonempty column headers, whole-number expected units of zero or more, and package units greater than zero. Barcode and name columns are optional. Review the preview before creating the order. Invalid files do not create a partial order.

Backup and recovery

From the library’s More menu, choose Export library backup. Keep the JSON file outside the app before uninstalling, changing devices or clearing device storage. There is no automatic sync between devices.

Restore a backup opens a preview of its source, orders and saved codes. Only Replace library replaces the current library; Cancel keeps it unchanged. This is replacement, not merging. Use Recover previous saved library to preview and recover the immediately preceding saved library. Subsequent saves change what “previous” means. Export your own backups for longer-term recovery.

If saving fails, resolve the reported issue, such as low storage, and retry. If a library cannot be read, it is kept and new writes are paused. You can save a copy of the unreadable file, preview the previous saved library or restore a known-good backup. Never uninstall to fix unreadable data before protecting your files.

Camera access

Camera access is requested only when you scan. Camera images are processed on device and are not saved or uploaded. If access is denied or no usable camera is available, type the code manually. You may change camera permission in iOS Settings.
